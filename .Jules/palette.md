## 2026-10-24 - Empty State Implementation for API-Driven Scaffold\n**Learning:** When building simple scaffold frontends (like Phase 1 scaffolds without full frameworks), relying solely on catching empty arrays on fetch is fragile if the initial state isn't visually communicated. The empty state pattern improves clarity.\n**Action:** Always include a visual empty state block (`<td colspan="x">`) in scaffold tables before data is hydrated or if data is empty.
